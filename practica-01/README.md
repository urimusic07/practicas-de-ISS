
# Práctica 01: Diseño de la BD de Estudiantes

## Propósito
crear y diseñar una base de datos para una universidad en la que pueda registrar a sus alumnos y tener un control de estos, contando con distintos caso de pruebas 
para el sistema para posteriormente hacer su a su codificación en C, documentando el flujo de trabajo mediante PSP y Git.

## Alcance
- Definición de entradas, salidas, restricciones y algoritmos en pseudocódigo para registrar y consultar alumnos.
- hacer un diseño modular sin usar para nada librerías externas, SGBD, frameworks o interfaces gráficas.
- No incluye código ejecutable en C ni base de datos real.

## Estructura de archivos
- `README.md`: Descripción general del proyecto y contenido de lo que vamos a encontrar en el repositorio.
- `1.- Resumen del plan del proyecto.docx`: Estimaciones iniciales de tiempo y datos de planeación (PSP).
- `Registro de tiempos.docx`: Bitácora detallada de tiempos invertidos por fase teniendo en cuenta cuanto fue el tiempo neto de cada fase y cuanto tiempo se perdio.
- `2.- Diseño.docx`: Especificación del problema, restricciones, entradas/salidas, modularización y pseudocódigo. 
- `4- Pruebas.docx`: Matriz con cuatro casos de pruebas en las que se introducen los datos de un estudiante ficticio y se realiza prueba de los modulos.
